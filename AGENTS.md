# Theia Story — contributor instructions

Read `README.md` for the canon authority hierarchy and `DECISIONS.md` for
creator decisions before editing. For Human campaign work, start with
`Theia/Campaigns/CURRENT_HUMAN_CAMPAIGN.md` and its linked canonical campaign
and editorial manifest.

- Preserve creator locks, approval classifications, provenance and open questions.
- Keep world truth separate from player knowledge and revelation timing.
- Narrative plans do not establish implemented or approved gameplay. Consult
  the sibling `../theia-mmo/docs/engineering/README.md` and relevant runtime
  documentation for engineering capabilities.
- Maintain relative Markdown links and existing file organization. Keep the
  sibling checkout names `theia-story` and `theia-mmo` for cross-repository links.
- Verify affected Markdown links and JSON syntax after edits. Record new
  creator decisions with date and scope; do not invent approvals.
- Keep credentials, private conversations/account exports and editor caches
  out of Git. Keep changes local until pushing is explicitly authorized.
